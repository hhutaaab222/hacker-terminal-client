🚀 GETTING STARTED

Requirements

Python 3.10 or newer

An internet connection

A terminal or command prompt

1. Download the game

Download or clone this repository to your computer.

2. Open the project folder

Open a terminal in the folder containing HACKER-TERMINAL-v1.0.py.

3. Install dependencies

python -m pip install -r requirements.txt

On some Linux systems, use python3 instead of python.

4. Launch the game

Windows:

python HACKER-TERMINAL-v1.0.py

Linux:

python3 HACKER-TERMINAL-v1.0.py

Make sure your game client is configured to connect to the online server.

🌐 CLOUD SAVES

The game uses an online backend to manage accounts and game progress.

Your progress can be available on different computers when you sign in to the same account.

An internet connection is required for online features.

🔒 SECURITY

Never publish passwords, API keys, database credentials, or .env files.

Do not share your account credentials.

The public game client does not contain the server's database connection secrets.

🛠️ TECHNOLOGY

Python — core game logic

Requests — HTTP communication with the server

Flask — backend API

PostgreSQL — account and save storage
